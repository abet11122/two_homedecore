# photos-inbox

Drop your own photos here, one folder per post:

```
photos-inbox/
  small-entryway-organization-ideas/
    hero.jpg        hero.txt       ← line 1: alt text, line 2: caption (optional)
    photo-1.jpg     photo-1.txt
```

Then run `npm run photos`. See `PHOTO-SHOT-LIST.md` in the project root for what to shoot for each post.

Everything in this folder except this README is ignored by git, so your originals stay on your computer.
